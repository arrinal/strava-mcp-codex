# Changelog

## 0.1.0 — 2026-06-02

Initial public release.

### Added

- Local stdio MCP server for Strava MCP.
- Support for Codex and other MCP clients that can run local stdio servers.
- Strava OAuth login with a local callback server.
- Local token refresh for Strava MCP access.
- Codex config install/status/uninstall commands.
- Health and tool-list commands for setup verification.
- Local config and token storage with private file permissions where supported.
- Redaction for tokens, client secrets, and Authorization headers in CLI output.
